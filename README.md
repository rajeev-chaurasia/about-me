# fredrin-apply

A personal site: a single page with four sections (Hero, What I've Shipped,
How This Page Was Built, Contact), built with Next.js (App Router),
TypeScript in strict mode and Tailwind CSS. It is a fully static export —
`npm run build` writes plain HTML/CSS/JS to `out/` — deployed via Vercel.
See [AGENTS.md](AGENTS.md) for commands and conventions.
